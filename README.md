# 简历速填

一个全局置顶的简历信息速填小窗（Electron 应用）。面试填表时，把常用个人信息、教育、项目、技能等以分组卡片形式悬浮在屏幕顶层，点击即可复制，免去反复翻找简历的麻烦。

## 功能特性

- **全局置顶悬浮窗**：始终浮于最前，随取随用；可一键切换置顶状态，收缩为托盘常驻。
- **分组卡片式展示**：按「基本信息、教育经历、工作经历、项目经历、技能证书」等分组与条目组织，支持折叠，导航栏可快速跳转。
- **点击即复制**：单击任意信息项即可将内容复制到剪贴板，超宽/换行内容自动补充悬浮提示显示完整值。
- **可配置默认折叠**：通过配置文件指定默认收缩的分组，简化常用视图。
- **一键打开文件夹**：工具栏文件夹图标可在资源管理器中打开指定文件夹（路径于配置中设置）。
- **托盘常驻**：关闭即隐藏到托盘，从托盘菜单显示/退出。

## 配置

配置文件 `settings.json`（首次启动由 `default-settings.json` 生成），主要字段：

| 字段 | 说明 |
|------|------|
| `title` | 窗口标题 |
| `defaultWidth` / `defaultHeight` | 默认窗口尺寸 |
| `defaultCollapsed` | 默认折叠的分组名数组 |
| `openFolder` | 文件夹图标按钮打开的路径（可为空） |
| `groups` | 分组与信息项数据，`entries.items` 为 `{ label, value }` |

修改配置后自动生效，或点击工具栏刷新按钮重新加载。本机配置 `settings.json` 已在 `.gitignore` 中忽略，不入库。

## 使用

```bash
npm install
npm start        # 启动应用
```

## 打包

```bash
npm run dist     # 生成 Windows 便携版（dist/）
```

- 原生 HTML / CSS / JavaScript（无前端框架）
